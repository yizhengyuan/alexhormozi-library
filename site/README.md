# 展示页

这是本仓库的公开网页，用来图形化、结构化地阅读档案，不是另一份正文。

- 入口：[index.html](../index.html)（发布后见 https://yizhengyuan.github.io/alexhormozi-library/ ）
- 页面用浏览器直接读取仓库里的 Markdown（`system/`、`sources/`、`RULES.md`），不另存一份内容。
- 更新思想地图或书目后，只要提交到 `main`，展示页会跟着变。
- 发布方式：GitHub Pages，分支 `main`，文件夹 `/ (root)`。根目录的 `.nojekyll` 是为了让 GitHub 不要用 Jekyll 把 `.md` 转成另一套页面，以便本页按原文读取。
