# 底层原则

## 短引与出处

`source: public`

只收录讨论所需的极短引用，必须带来源（作品名、日期、链接或可定位信息）。不要在此堆积语录全集。

（暂无已核对的短引。有了可公开核对的出处后，按条追加，并互链到 [`../sources/`](../sources/)。）

## 我们的整理

`source: synthesis`

贯穿各段、我们目前归纳出的方法大致是：

- 先做简单、可重复的动作，用现金结果检验，而不是先把理论做复杂。
- 价格是筛选手段，不是主要竞争手段；先把价值做够，再配相应的价格。
- 量和技能一起抓：没有量，技能练不出来；只有量没有技能，效率上不去。
- 整理必须可回溯：任何一条作为「他的观点」写出的话，最终要能回到公开出处。若只是我们的归纳，就标明 `synthesis`。

这些原则来自公开讨论中的反复出现，以及本项目自己的编辑纪律，不是他某次亲口列出的清单。
